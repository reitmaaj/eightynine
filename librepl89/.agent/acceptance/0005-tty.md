# librepl89 acceptance tests — POSIX terminal session

## 0009 — Unacceptable behavior (must reject / fail safely)

- TY-09. A non-tty input descriptor MUST be rejected with `REPL89_ETTY`;
  raw mode MUST NOT be attempted.
- TY-10. `TIOCGWINSZ` failure (or a zero column count) MUST return
  `REPL89_EIO`; the editor MUST NOT guess a terminal size.
- TY-11. `leave` after a failed `enter` MUST be a safe no-op.
- TY-12. After `leave`, the saved termios state MUST be restored exactly;
  the terminal MUST NOT remain in raw mode.

## 0010 — Required behavior (must exhibit)

- TY-01. Entering raw mode disables ICANON, ECHO, ISIG, and OPOST and sets
  VMIN=1, VTIME=0.
- TY-02. Session start emits the bracketed-paste enable sequence
  (`CSI ? 2004 h`) on the output descriptor.
- TY-03. Session end emits the bracketed-paste disable sequence
  (`CSI ? 2004 l`).
- TY-04. `TIOCGWINSZ` is observed and rows/columns are reported.
- TY-05. Reads and writes pass bytes through the terminal descriptors.
- TY-06. `repl89_tty_write` writes all bytes even when the descriptor
  accepts short writes.
- TY-07. Terminal restoration on submit, cancel, EOF, and error is exercised
  by the session increment (R6); the tty layer's `leave` is the single
  restoration path.
- TY-08. The application owns `SIGWINCH`; the library installs no signal
  handler.
