# BDD scenarios: golden byte fixtures (L11)

These scenarios drive `test/golden/test_golden.c` against the frozen fixtures
under `test/golden/`, generated by `test/tools/gen_golden.c` via
`just golden-gen`. IDs cross-reference
`.agent/acceptance/0011-golden-fixtures.md`.

- SCENARIO Encode freeze: GIVEN the frozen fixture ledger WHEN the same
  append/rotate/sync sequence runs on a fresh ledger THEN the produced sealed
  and active segment files are byte-identical to the fixtures (GF01).
- SCENARIO Decode freeze: GIVEN a directory seeded with the frozen fixture
  files WHEN opened and read/iterated THEN the exact indices, tags, and
  payload bytes return (GF02).
- SCENARIO Corrupt fixture: GIVEN a byte-flipped copy of a frozen fixture WHEN
  the affected record is read THEN `LEDGER89_ERR_CORRUPT` and no payload bytes
  are returned (GF03).
