# libcat89 testing scenarios (BDD)

## 0001-core.md — category core and lifetime

- SCENARIO compose ordering: GIVEN composable `f:A->B`, `g:B->C` WHERe reversed
  order `f o g` is ill-typed WHEN `cat89_compose(c,g,f,&out)` runs THEN `out`
  equals `g o f` with `dom(out)=A` and `cod(out)=C`.
- SCENARIO domain mismatch rejected: GIVEN `f:A->B`, `q:C->D` with B != C WHEN
  `cat89_compose(c,q,f,...)` runs THEN result is `CAT89_DOMAIN` and backend
  `compose` is not invoked by the generic wrapper.
- SCENARIO identity typing: GIVEN object A WHEN `cat89_identity(c,A,&i)` runs
  THEN `dom(i)=A` and `cod(i)=A`.
- SCENARIO status propagation: GIVEN a backend that returns `CAT89_NOMEM` from
  compose WHEN the generic wrapper calls it THEN the wrapper returns
  `CAT89_NOMEM` (never `CAT89_CALLBACK`).
- SCENARIO out-param reset: GIVEN a failing operation with a pre-set non-null
  pointer out WHEN it runs THEN `*out == NULL`.

## 0002-capabilities-finite.md — capabilities, finite oracle, checker

- SCENARIO exhaustive finite laws: GIVEN a finite fixture category (terminal,
  D2, walking arrow, Comp2/Comp3, C2, parallel pair, diamond poset) WHEN the
  exhaustive category checker runs THEN all identity and associativity cases
  pass and checked-counts match an independent loop.
- SCENARIO enumeration exactness: GIVEN the walking arrow WHEN object/morphism/
  hom enumeration iterates THEN |Ob|=2, |Mor|=3, Hom(A,B)={f}, Hom(B,A) empty.
- SCENARIO capability independence: GIVEN a category with no eq and no enum WHEN
  core, iso, split, functor, opposite operations run THEN they succeed; only
  checkers that explicitly require a missing capability fail with
  `CAT89_NOT_SUPPORTED`.
- SCENARIO malformed law rejected: GIVEN a mock category violating left identity
  / right identity / associativity WHEN the corresponding local checker runs
  THEN it reports invalid (0).

## 0003-algebra.md — functor, nat, iso, split

- SCENARIO functor laws: GIVEN a functor F over a finite source WHEN checking
  THEN F(1_A)=1_{F(A)} and F(g o f)=F(g) o F(f) for all composable pairs.
- SCENARIO naturality: GIVEN `eta:F=>G` and `f:A->B` WHEN the naturality checker
  runs THEN G(f) o eta_A = eta_B o F(f).
- SCENARIO iso inverse laws: GIVEN iso (f,g) THEN g o f = 1 and f o g = 1;
  invert(invert(i)) equals i componentwise.
- SCENARIO non-entanglement: GIVEN one pair of morphisms used as iso, split-mono
  and split-epi simultaneously THEN creating/destroying any wrapper leaves the
  underlying morphisms and the other wrappers unchanged (CAT-I3).

## 0004-constructions.md — generic categories and universal structure

- SCENARIO opposite reverses: GIVEN `f:A->B`,`g:B->C` in C THEN in C^op,
  f^op o g^op = (g o f)^op and dom/cod are swapped. Double opposite behaves
  equivalently to C (not pointer-identical).
- SCENARIO product composition componentwise: GIVEN product category C x D THEN
  (f2,g2) o (f1,g1) = (f2 o f1, g2 o g1) and identities are (1_A,1_B).
- SCENARIO slice triangle: GIVEN C/A objects f:X->A, g:Y->A WHEN h:X->Y is a
  morphism THEN g o h = f is required; non-commuting h is invalid under checker.
- SCENARIO limit uniqueness: GIVEN a finite claimed limit cone L over diagram D
  WHEN every candidate cone K is factored and every morphism candidate.apex ->
  L.apex is enumerated THEN exactly one satisfies the factor equations.
- SCENARIO wrapper categories obey laws: GIVEN opposite/product/arrow/slice/
  coslice/comma over finite bases WHEN the exhaustive category checker runs with
  finite support THEN all cases pass (ICD-I10).
- SCENARIO duality: GIVEN product in C and coproduct in C^op, equalizer vs
  coequalizer^op, slice vs coslice^op THEN the dual constructions agree.
