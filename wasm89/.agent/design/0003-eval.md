# Design: evaluator core (Phase A)

Ports the reference interpreter's `step`/`eval` (`eval.ml`) for the
control-flow core subset. Later phases add `Invoke`/`Frame` (B), memory/
table/bulk/ref ops (C), and `Throwing`/`Handler` (D) on the same model.

## Value model (`src/eval.h`)

```
w89_value = { is_ref : u32 } + union { u64 num | w89_ref ref }
w89_ref   = { kind } + union { funcinst *func | u64 ext | exn *exn }
w89_exn   = { taginst *tag, value *args, u32 nargs }     (* ExnRef payload *)
w89_taginst = { const ft * }                              (* identity = address *)
w89_globalinst = { globaltype type, value value }
w89_meminst / w89_tableinst = type/limits shells (contents land in Phase C)
w89_funcinst = Phase B
```

Numeric values are stored as raw bit patterns in a `u64`; the type of a
number is known from validation, exactly like the reference's untyped
`Num`. Reference kinds are null/func/extern/exn; `ref_null`/`ref.func`/
etc. construct them (exn refs serve `throw_ref`/`catch_ref` in Phase D).

## Instances

`w89_moduleinst` holds pointers to the store-side instances a module
references: flattened types (`w89_typeenv`), funcs, tables, memories,
globals, tags, datas, elems. Instances are heap objects; **tag identity is
pointer equality**, and an imported tag resolves to the exporting module's
tag instance object. The full store container lands in Phase B.

## Config / code

```
w89_config = { frame, code, budget, crash }
w89_frame  = { inst, locals[], nlocals }        (locals carry a set flag)
w89_code   = { vs, front[], back[], bhead }     (a deque)
```

`w89_code` is a deque with two ends: a LIFO `front` and an indexed `back`.
`step` consumes the next item (front top, else `back[bhead]`) and the
reference's `es' @ List.tl es` is implemented O(1) by pushing `es'` onto
`front` (reversed) and leaving `back` untouched. Nothing is ever shifted.

Each nested block/loop/if/try_table body becomes a nested `w89_code` owned
by a `Label` (later `Handler`) admin instruction, mirroring the
reference's `Label (n, es0, (vs', es))`.

## Admin instructions

`Plain`, `Refer`, `Invoke`, `Breaking`, `Returning`, `ReturningInvoke`,
`Throwing`, `Trapping`, `Label`, `Frame`, `Handler` — the exact
`admininstr` set of the reference, so the `Label`/`Frame`/`Handler` step
cases can be ported verbatim (Handler cases in Phase D).

Plain instructions are borrowed from the module's flat decoded
instruction vector; a plain instr carries `{items, nitems, ipos}` so that
block extents (`w89_block_extent`: body start, else position, end) can be
recomputed by scanning — mirroring `check_block_body`. `Loop` re-entry
stores the loop opener as the label continuation (`es0`).

## `step` (ported cases, Phase A subset)

* `Const`/`Nop`/`Drop`/`Select`/`SelectT`, `LocalGet/Set/Tee`,
  `GlobalGet/Set` — per reference, including "read of uninitialized
  local", "write to immutable global", "stack underflow" crashes.
* `Block`/`Loop`/`If` — `split n1` the params, push `Label(n, es0, body)`;
  `If` desugars to a `Block` of the chosen arm.
* `Br`/`BrIf`/`BrTable` — `Breaking (k, vs)` capturing the value stack;
  `br_table` uses `xs[i]` else the default.
* `Return` — `Returning vs`.
* `Unreachable` — `Trapping "unreachable executed"`.
* Numeric `Test`/`Compare`/`Unary`/`Binary`/`Convert` — call `numeric.c`,
  mapping divide-by-zero, INT_MIN/-1 overflow and invalid conversions to
  the reference trap messages.
* `Label` cases: empty body merges `vs' @ vs`; `Breaking 0` takes `n`
  values and continues `es0`; deeper `Breaking` decrements; jumping heads
  (trap/return/throw) propagate outward discarding the pending body.
* `Breaking`/`Returning` at top level crash "undefined label"/"undefined
  frame"; `Trapping`/`Throwing` heads terminate `eval` (trap/exception).

## `eval`

Loops `step` until the code deque is empty (normal: move the value stack
to the result), the head is `Trapping` (trap with message), the head is
`Throwing` (exception with tag + carried values, Phase D), or `step`
reports a crash/exhaustion.

## Lifecycle

`w89_config` is heap-free (all arrays grow via `realloc`); plain
instructions borrow the module, admin instructions own their nested
codes, carried value lists and (later) frames, freed by `w89_config_free`
recursively. `w89_eval` transfers the final value stack to the caller and
frees the rest on non-normal termination.

## Why a faithful deque port

The reference's `Label`/`Handler`/`Frame` wrapping with `is_jumping`
propagation is the semantics of exceptions, stack polymorphism and
tail-call-adjacent control flow. Reusing the same admin-instruction
structure now means Phase D's `Handler` catch cases drop in unchanged and
trap/throw/return propagation is already correct.
