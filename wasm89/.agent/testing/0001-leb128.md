# Testing: LEB128 integer decoding

*BDD scenarios for the values milestone (spec 5.2.2 Integers). Bundled
here are all LEB128 scenarios; numeric operations get their own file.*

## LEB-U Unsigned LEB128 (uN)

SCENARIO LEB-U-001: Valid unsigned encodings decode
GIVEN a byte buffer containing a well-formed unsigned LEB128 encoding of
N bits (N in {8, 32, 64})
WHEN the decoder reads it
THEN it returns success
AND yields the decoded value
AND advances the cursor past the encoded bytes.

SCENARIO LEB-U-002: Overlong encodings within the byte bound are valid
GIVEN an unsigned LEB128 encoding that uses extra bytes
    but no more than ceil(N/7) bytes and whose value fits in N bits
    (e.g. 0x83 0x00 as u8 decodes to 3)
WHEN the decoder reads it
THEN it returns success.

SCENARIO LEB-U-003: Malformed unsigned encodings are rejected
GIVEN an unsigned LEB128 encoding that is too long
    (more than ceil(N/7) bytes), or whose unused bits are non-zero
    (e.g. 0x83 0x10 as u8), or that is truncated (buffer ends before a
    terminal byte)
WHEN the decoder reads it
THEN it returns failure
AND it must NOT report a value or advance the cursor.

## LEB-S Signed LEB128 (sN)

SCENARIO LEB-S-001: Valid signed encodings decode
GIVEN a byte buffer containing a well-formed signed LEB128 encoding of
N bits, including negative values and the extremes
    (-2^31 and 2^31-1 as s32, -2^63 and 2^63-1 as s64)
WHEN the decoder reads it
THEN it returns success
AND yields the sign-extended value
AND advances the cursor.

SCENARIO LEB-S-002: Overlong signed encodings within the bound are valid
GIVEN an encoding such as 0xFE 0xFF 0x7F as s16 (value -2)
WHEN the decoder reads it
THEN it returns success and yields -2.

SCENARIO LEB-S-003: Malformed signed encodings are rejected
GIVEN an encoding with sign-inconsistent unused bits (0x83 0x3E or
    0xFF 0x7B as s8), or one too long, or one truncated, or one whose
    sign extension does not fit in N bits (e.g. 0xFF 0xFF 0xFF 0xFF 0x0F
    as s32)
WHEN the decoder reads it
THEN it returns failure
AND it must NOT report a value or advance the cursor.
