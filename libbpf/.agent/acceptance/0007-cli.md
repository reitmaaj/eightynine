# 0007 - Acceptance: CLI

*Acceptance criteria for the CLI milestone. Each item is either a behaviour
the software MUST exhibit or a behaviour it MUST reject.*

## MUST

* `bpf run <file>` MUST decode, validate, and execute the program and, on a
  clean EXIT, print the value of r0 and exit 0.
* `bpf dis <file>` MUST print one line per decoded instruction and exit 0.
* `bpf groups <file>` MUST print the names of the conformance groups required
  by the program (including the always-required `base32`) and exit 0.
* `bpf version` MUST print `1` and exit 0.

## MUST NOT

* `bpf run` MUST NOT report success for a program that is invalid, truncated,
  falls off the end, exceeds the step budget, or traps on an out-of-bounds
  memory access; each MUST exit nonzero with an error message.
* `bpf <cmd> <path>` MUST NOT succeed when the file cannot be read; it MUST
  exit nonzero.
* `bpf` MUST NOT exit 0 for an unknown subcommand or missing argument.
