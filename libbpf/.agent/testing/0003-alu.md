# 0003 - Testing: ALU/ALU64 arithmetic and byte swap

*BDD scenarios for the evaluator arithmetic milestone (RFC 9669 section 4.1,
4.2). Related items are bundled.*

## 0003-001 Register file

SCENARIO: Register file holds eleven 64-bit registers
GIVEN a fresh bpf_regs
WHEN registers are read
THEN all eleven registers are zero.

## 0003-002 ALU64 basic arithmetic

SCENARIO: 64-bit ADD, SUB, MUL, OR, AND, XOR compute with wrap
GIVEN a register file with dst set to A
WHEN an ALU64 ADD/SUB/MUL/OR/AND/XOR with source X or K executes
THEN the destination holds the wrapped 64-bit result.

## 0003-003 ALU32 zero-extends

SCENARIO: 32-bit operations zero the upper 32 bits
GIVEN a destination holding a value with nonzero upper 32 bits
WHEN a 32-bit ALU operation executes
THEN the upper 32 bits of the destination are zero.

## 0003-004 Division by zero

SCENARIO: Division by zero yields zero
GIVEN an ALU64 DIV or SDIV with source operand zero
WHEN it executes
THEN the destination is set to 0.

## 0003-005 Modulo by zero

SCENARIO: 64-bit modulo by zero leaves the destination unchanged
GIVEN an ALU64 MOD or SMOD with source operand zero
WHEN it executes
THEN the destination value is unchanged.

SCENARIO: 32-bit modulo by zero zeroes the upper 32 bits
GIVEN an ALU MOD or SMOD with source operand zero
WHEN it executes
THEN the upper 32 bits of the destination are zero.

## 0003-006 Signed modulo uses truncated division

SCENARIO: Signed modulo matches truncated (C) division
GIVEN ALU64 SMOD with dividend -13 and divisor 3
WHEN it executes
THEN the destination is -1.

## 0003-007 Shift masks

SCENARIO: 64-bit shifts mask the count by 0x3F
GIVEN an ALU64 LSH/RSH/ARSH with count 70
WHEN it executes
THEN the shift count used is 6.

SCENARIO: 32-bit shifts mask the count by 0x1F
GIVEN an ALU LSH/RSH/ARSH with count 34
WHEN it executes
THEN the shift count used is 2.

## 0003-008 NEG

SCENARIO: NEG negates the destination
GIVEN a destination holding value V
WHEN an ALU64 NEG executes
THEN the destination holds the two's-complement negation of V.

## 0003-009 MOV

SCENARIO: MOV K sign-extends the 32-bit immediate into 64 bits
GIVEN an ALU64 MOV K with imm -1
WHEN it executes
THEN the destination holds all-ones (sign-extended).

SCENARIO: MOV X copies the source register
GIVEN an ALU64 MOV X from a source register
WHEN it executes
THEN the destination equals the source register value.

## 0003-010 MOVSX

SCENARIO: MOVSX sign-extends an 8/16/32-bit operand
GIVEN an ALU64 MOVSX X with offset 8/16/32 from a register whose low bits
      carry a sign
WHEN it executes
THEN the destination is the sign-extended operand.

## 0003-011 Byte swap

SCENARIO: ALU64 END swaps bytes for width 16, 32, 64
GIVEN an ALU64 END instruction with imm width 16/32/64
WHEN it executes
THEN the destination bytes are reversed within the width.

SCENARIO: ALU END BE swaps bytes
GIVEN an ALU END BE instruction with imm width 16/32/64
WHEN it executes
THEN the destination bytes are reversed within the width.

## 0003-012 Immediate source for ALU64

SCENARIO: ALU64 K source is sign-extended
GIVEN an ALU64 ADD K with imm 0xFFFFFFFF
WHEN it executes
THEN the source operand is -1 (sign-extended to 64 bits).
