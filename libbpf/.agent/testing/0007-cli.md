# 0007 - Testing: CLI

*BDD scenarios for the CLI milestone. Related items are bundled.*

## 0007-001 run executes and prints the result

SCENARIO: Running a program prints r0 on exit
GIVEN a bytecode file for `r0 = 42; exit`
WHEN `bpf run <file>` runs
THEN it exits 0
AND it prints `42`.

## 0007-002 run rejects invalid bytecode

SCENARIO: Invalid bytecode is reported (unacceptable behaviour)
GIVEN a bytecode file with a truncated wide instruction
WHEN `bpf run <file>` runs
THEN it exits nonzero
AND it prints an error message.

SCENARIO: A program that falls off the end is rejected
GIVEN a bytecode file with no EXIT
WHEN `bpf run <file>` runs
THEN it exits nonzero
AND it prints an error message.

## 0007-003 dis prints instructions

SCENARIO: Disassembly lists each decoded instruction
GIVEN a bytecode file with two instructions
WHEN `bpf dis <file>` runs
THEN it exits 0
AND it prints one line per instruction.

## 0007-004 groups prints conformance groups

SCENARIO: Conformance groups are reported
GIVEN a bytecode file using a 64-bit ALU instruction
WHEN `bpf groups <file>` runs
THEN it exits 0
AND it prints `base32` and `base64`.

## 0007-005 missing file is rejected

SCENARIO: A missing file is an error (unacceptable behaviour)
GIVEN a nonexistent path
WHEN `bpf run <path>` runs
THEN it exits nonzero
AND it prints an error message.
